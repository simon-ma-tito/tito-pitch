痛點與願景

人走，知識也被帶走

Dirty Data 與隱性工作流，既是痛點，也是我們的護城河。

企業的痛點

  • 人走，知識也被帶走
  • Dirty Data (髒資料)非結構化、散落各處的企業資料
  • 隱性工作流只有產業內部人才懂的做事方式
→

我們的願景

為企業打造一套方式，
讓知識留存在公司。

很多公司需要協助才能完成光靠自己，或只用 AI，都做不到，需要顧問協助。
這是普遍性的需求也有很多工具需要被打造出來，才能達成這個目標。

我們希望為台灣打造一個指標性的軟體公司

解決之道

知識固化引擎：從個人能力，到團隊能力

  • 01
    知識固化引擎用 Agent，讓工作從個人能力，變成團隊能力。Agent 既是工具，也是載體，承載企業的知識。
  • 02
    FDE：服務的存在許多公司需要服務，前線部署工程師（FDE）正是做這件事的人。我預期這個需求會持續相當久。
  • 03
    先服務，再封裝服務先有收入；累積專案後封裝成產品，服務加上一些產品，就能打平。
先做服務服務先有收入
累積專案沉澱通用的 Agent 工作流
封裝成產品可規模化複製
服務＋產品收入打平，再成長
飛輪越轉越快
